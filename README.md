# Desocupados Modpack
## Como jogar
- Baixe o Prism Launcher [original](https://github.com/PrismLauncher/PrismLauncher) ou [pirata](https://github.com/Diegiwg/PrismLauncher-Cracked)
- Baixe o modpack [aqui](https://drive.google.com/file/d/1gTHoW5hW8AxJsGgx4y-s0iGhW8qW-NVl/view?usp=sharing)
- No Prism Launcher, vá em 'Adicionar instancia' e 'Importar'
- Selecione o .zip baixado
- Abra o jogo e se divirta!
